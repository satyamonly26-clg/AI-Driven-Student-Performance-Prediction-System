# 🎓 AI-Driven Student Performance Prediction System

## 📌 Overview
This project predicts a student's final exam performance using Machine Learning.

### Input Features
- Attendance (%)
- Internal Test 1
- Internal Test 2
- Assignment Score
- Daily Study Hours

### Output
- Predicted Final Exam Marks
- Grade
- Performance Category
- Pass/Fail Status
- Study Recommendations

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regressor
- Streamlit
- Joblib

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
